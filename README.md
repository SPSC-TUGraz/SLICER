# SLICER

A Tool for Efficient Stimuli Extraction from Large Speech Corpora.

## Installation
- Clone repository `git clone https://github.com/SPSC-TUGraz/SLICER.git`.
- Change your directory to the path where you cloned the repo `cd path/with/SLICER`. 
- Install package with `pip install .` 
(If the installation complains about missing `tkinter` package, install separately, e.g., with `sudo apt-get install python3-tk`.)


## Usage
Run script with `python3 tgslicer.py`
